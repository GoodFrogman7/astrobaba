# Working in this repo

Read docs/PLAN.md §0 and §6 before changing anything; they are non-negotiable. Short version:

- One phase at a time. Finish, run `make ci`, show proof, stop and wait for the go-ahead.
- Money code (wallet, billing, refunds) is test-first.
- Never invent astrology data. Values come from the engine or `/data`; fixtures in `/evals/astro`
  are filled by scripts from cited sources, never typed by hand or generated by an LLM.
- Secrets only in `.env`. Never log chat content, phones, emails or birth details.
- No dark patterns (fake online counts, scarcity timers, AI presented as human).
- Do not read docs/reference/astrotalk-teardown.md in full; open only the sections a phase cites.
- After each phase update docs/ARCHITECTURE.md and add ADRs for non-obvious decisions.

Commands: `make dev`, `make ci`, `make help`. TS in `apps/*`, `packages/*` (pnpm); Python in
`services/*` (uv workspace, run tools with `uv run`). Shared contracts are JSON in
`packages/shared` and are read by both languages.
